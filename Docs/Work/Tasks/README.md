# Task files

Create cross-session task files here from
[`../../Templates/TASK_TEMPLATE.md`](../../Templates/TASK_TEMPLATE.md).

- Use sequential IDs such as `TASK-0001-repair-runtime.md`.
- Add every active task to [`../ACTIVE.md`](../ACTIVE.md).
- Keep ownership and source/configuration scope explicit to prevent conflicting edits.
- Record facts checked against source, Git, tests, bounded probes, or container output.
- On completion, remove the active row and archive the file only when its history remains useful.

Do not use task files as chat transcripts or minute-by-minute work diaries.
